ETHICAL HACKING TOOLS & THEIR PURPOSES

1. Nmap: Scans networks to find active devices, open ports, and running services.
2. Wireshark: Captures and analyzes network traffic (packets) in real-time.
3. Burp Suite: Intercepts and modifies web traffic to find website vulnerabilities.
4. Metasploit: A framework used to develop and execute exploit code against a target.
5. Hashcat: A powerful tool used to crack encrypted passwords (hashes).
6. SQLmap: Automatically detects and exploits SQL injection flaws in databases.
7. Aircrack-ng: A suite used to assess Wi-Fi security and crack wireless passwords.
8. Nikto: Scans web servers for dangerous files, outdated software, and misconfigurations.
9. Social-Engineer Toolkit (SET): Automates social engineering attacks like phishing.
10. Netcat: A utility that reads/writes data across network connections; the "Swiss Army Knife."

Part 2: The Top 80 Linux Commands with Meanings
Plaintext

LINUX COMMANDS CHEAT SHEET (With Meanings)

--- NAVIGATION & FILES ---
1. pwd: Print Working Directory (shows exactly where you are).
2. ls: List files and folders in the current directory.
3. cd: Change Directory (move to a different folder).
4. mkdir: Make Directory (create a new folder).
5. touch: Create a new empty file.
6. cp: Copy files or directories.
7. mv: Move or rename files or directories.
8. rm: Remove (delete) files.
9. rmdir: Remove an empty directory.
10. ln: Link (create a shortcut to a file).

--- READING & EDITING ---
11. cat: Concatenate (display the entire contents of a file).
12. less: View a file one page at a time (better for large files).
13. head: Show the first 10 lines of a file.
14. tail: Show the last 10 lines of a file (useful for logs).
15. grep: Global Regular Expression Print (search for text within files).
16. nano: Simple, beginner-friendly text editor.
17. vi / vim: Advanced, powerful text editor found on almost all Linux systems.
18. diff: Compare two files and show the differences.
19. sort: Sort lines of text alphabetically or numerically.
20. uniq: Report or omit repeated lines in a file.

--- PERMISSIONS & USERS ---
21. chmod: Change Mode (change file/folder permissions).
22. chown: Change Owner (change who owns the file/folder).
23. sudo: SuperUser Do (run a command with admin privileges).
24. su: Switch User (log in as another user).
25. passwd: Change a user's password.
26. umask: Set default permissions for new files.
27. chgrp: Change Group (change the group ownership of a file).
28. lsattr: List file attributes on a Linux file system.
29. chattr: Change file attributes (like making a file "immutable").
30. whoami: Displays the username of the current user.

--- NETWORKING ---
31. ip addr: Show or manage IP addresses and network interfaces.
32. ping: Send a request to a host to check if it is reachable.
33. netstat: Show network connections, routing tables, and statistics.
34. ss: Modern replacement for netstat; faster and more detailed.
35. traceroute: Print the path that packets take to a network host.
36. dig: DNS lookup utility to find domain information.
37. nslookup: Older utility for querying DNS servers.
38. curl: Transfer data to/from a server (supports HTTP, FTP, etc.).
39. wget: Non-interactive network downloader (downloads files from URLs).
40. ssh: Secure Shell (log into a remote computer securely).
41. scp: Secure Copy (copy files between computers over SSH).
42. nmap: Network Mapper (scans for open ports and services).
43. tcpdump: Command-line packet sniffer to monitor network traffic.
44. iptables: Administration tool for IPv4 packet filtering (Firewall).
45. ufw: Uncomplicated Firewall (an easier way to manage iptables).

--- SYSTEM INFO & PROCESSES ---
46. top: Display live system resource usage and running processes.
47. htop: Interactive and colorful process viewer (easier than 'top').
48. ps: Process Status (shows a snapshot of currently running programs).
49. kill: Send a signal to a process to stop it (usually by ID).
50. pkill: Stop a process based on its name instead of ID.
51. df: Disk Free (shows available disk space).
52. du: Disk Usage (shows how much space a file/folder uses).
53. free: Display amount of free and used system memory (RAM).
54. uname -a: Print all system information (Kernel version, etc.).
55. uptime: Show how long the system has been running.
56. lscpu: Display information about the CPU architecture.
57. lsusb: List USB devices currently connected to the system.
58. dmesg: Print messages from the kernel (useful for hardware errors).
59. journalctl: Query and display logs from the systemd journal.
60. vmstat: Report virtual memory statistics.

--- PACKAGE MANAGEMENT ---
61. apt update: Update the list of available software packages.
62. apt upgrade: Install the newest versions of all current packages.
63. apt install: Download and install a specific software package.
64. apt remove: Uninstall a specific software package.
65. apt search: Search for a software package by name or description.
66. dpkg -i: Install a .deb package file manually.

--- DISK MANAGEMENT ---
67. mount: Attach a filesystem (like a USB drive) to the system.
68. umount: Unmount (detach) a filesystem from the system.
69. fdisk: View or manage disk partition tables.
70. lsblk: List information about all available block devices (drives).
71. mkfs: Build/Format a Linux filesystem on a device.
72. dd: Convert and copy files (used for creating bootable drives).

--- MISC / QUALITY OF LIFE ---
73. alias: Create a custom shortcut name for a long command.
74. history: Show a list of all recently typed commands.
75. clear: Clear the terminal screen.
76. man: Manual (shows the help manual for any command).
77. echo: Display a line of text or a variable.
78. export: Set environment variables (values the system remembers).
79. find: Search for files in a directory hierarchy.
80. exit: Close the current terminal session or log out.

## Task Summary (DHCP)

This task is a hands-on DHCP lab using **GNS3** and **Wireshark**.

You need to:

1. **Add a virtual PC (vPC)** to your existing GNS3 project and connect it to one Cisco router interface.
2. **Configure the router interface** connected to the vPC with an IP address in the `10.10.30.0/24` subnet.
3. **Configure a DHCP server on the router**:
   - Create a DHCP address pool.
   - Allocate 50 IP addresses from the `10.10.30.0/24` network.
4. **Capture network traffic on the link between the router and vPC** using Wireshark **before** the vPC requests DHCP.
5. **On the vPC, request an IP via DHCP** using the `dhcp` command.
6. **Verify the vPC gets an IP address from the DHCP pool.**
7. **Ping the router’s interface from the vPC** to verify connectivity.
8. **Analyze the captured traffic**:
   - Apply the filter `dhcp` in Wireshark.
   - Observe the DHCP DORA process (Discover, Offer, Request, Acknowledge).
9. **Answer the assignment questions:**
   - What does “DORA IP ….” mean in DHCP?
   - To what IP address is the first DHCP packet sent?
10. **Save your deliverables:**
    - The GNS3 project file.
    - The Wireshark capture saved as `dhcp.pcap`.
    - A text file named `dhcp` with your answers.

## What Is the Point of This Quest?

This quest helps you understand the DHCP protocol in practice — how IP addresses are dynamically assigned on a network.

Specifically, it teaches you to:

- Configure a **DHCP server** on a Cisco router.
- Understand how a client requests and receives an IP via DHCP (DORA process).
- Use **Wireshark** to observe DHCP packets on the wire.
- See how DHCP uses broadcast messages and UDP ports 67/68.
- Interpret DHCP lease assignments and traffic.
- Practice troubleshooting and verifying DHCP configuration in a real network simulator.

## DHCP Configuration Project Guide — GNS3 with Cisco Routers and vPC

### 1. Setup Topology

- Use your existing GNS3 project with one router (R1).
- Add a virtual PC (vPC) and connect it to R1’s interface (e.g., FastEthernet0/1).
- Assign IP subnet `10.10.30.0/24` to the router interface connected to the vPC.

### 2. Configure Router Interface

```bash
R1> enable
R1# configure terminal
R1(config)# interface fastEthernet0/1
R1(config-if)# ip address 10.10.30.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

###3. Configure DHCP Pool on Router

R1(config)# ip dhcp excluded-address 10.10.30.1 10.10.30.10
R1(config)# ip dhcp pool GUEST_POOL
R1(dhcp-config)# network 10.10.30.0 255.255.255.0
R1(dhcp-config)# default-router 10.10.30.1
R1(dhcp-config)# lease 1
R1(dhcp-config)# exit

Explanation:

- Excluded addresses won’t be assigned (e.g., router and reserved IPs).

- Pool GUEST_POOL allocates IPs from 10.10.30.11 to 10.10.30.254 (50 addresses or more).

- Default gateway set to router’s interface IP.

###4. Start Packet Capture

- In GNS3, right-click the link between R1 and vPC and start Wireshark capture before you run DHCP on the vPC.

###5. Request DHCP IP on vPC

vPC> dhcp

- The vPC will broadcast a DHCP Discover to find the server.

###6. Verify IP Assignment on vPC

vPC> show ip

You should see an IP in 10.10.30.x assigned.

###7. Ping Router from vPC

vPC> ping 10.10.30.1

Confirm ping is successful.

###8. Analyze DHCP Traffic in Wireshark

- Use filter:

Wireshark: dhcp

- Look for these packets in order (DORA):

#Discover (client → broadcast 255.255.255.255)
#Offer (server → client)
#Request (client → server)
#Acknowledge (server → client)

###9. Answer the Questions for Your dhcp Text File

- “DORA” means: The sequence of DHCP packets used to assign an IP dynamically:

Discover, Offer, Request, Acknowledge.

The first DHCP packet is sent to: the broadcast IP 255.255.255.255.

###10.Useful Cisco IOS and GNS3 Commands for DHCP

Show DHCP pools and leases: show ip dhcp pool     show ip dhcp binding

Check interface status: show ip interface brief

Remove excluded addresses (if needed): no ip dhcp excluded-address 10.10.30.1 10.10.30.10

Clear DHCP bindings and lease information: clear ip dhcp binding *
 
Disable/enable DHCP server on router: no service dhcp   service dhcp

Restart GNS3 capture on a link: Right-click the link → Start/Stop capture.

Filter DHCP packets in Wireshark: dhcp

Check assigned IP on vPC: show ip

Request IP via DHCP on vPC: dhcp

###Summary Notes

- DHCP automates IP assignment and configuration on networks.

- It uses broadcast messaging to communicate initial requests.

- DORA process is fundamental for DHCP operation.

- Correct setup of DHCP pools, excluded addresses, and router interface is essential.

- Wireshark is a powerful tool to observe DHCP traffic in real-time.

- Always start capture before the DHCP client requests an IP to see the full process.

###1. Intro

The PC shouldn't have to care if a router dies. Usually, a PC has one "Default Gateway."
If that router burns out, the PC is stuck. With HSRP, we give the PC a Virtual IP (VIP) as its gateway.
R1 and R2 then "fight" behind the scenes to see who gets to be the active one.

###2. Summary

#Topology: R1 and R2 both connect to a central Switch. The PC also connects to that Switch.

#Subnet: 192.168.1.0/24

#Physical IPs: R1: .2, R2: .3, PC: .10

#Virtual IP (The Gateway): 192.168.1.1

###3. Solution (The Config)

##Step A: IP Addressing

First, we set the real, physical IPs on the interfaces connected to the switch.

#On R1:

#Bash

conf t
interface f0/0
  ip address 192.168.1.2 255.255.255.0
  no shutdown

#On R2:

#Bash

conf t
interface f0/0
  ip address 192.168.1.3 255.255.255.0
  no shutdown

##Step B: HSRP Configuration
Now we create the "Team" (Group 1). We want R1 to be the boss (Active) and R2 to be the backup (Standby).

#On R1 (The Active Primary):

#Bash

interface f0/0
  standby 1 ip 192.168.1.1          # This is the Virtual Gateway
  standby 1 priority 110            # Higher priority (Default is 100) wins
  standby 1 preempt                 # Allows R1 to take over if it reboots

#On R2 (The Standby Backup):

#Bash

interface f0/0
  standby 1 ip 192.168.1.1          # Must be the SAME virtual IP
  standby 1 priority 100            # Lower priority = Backup
  standby 1 preempt

##Step C: PC Configuration
In your VPCS, set the IP and use the Virtual IP as the gateway.

#Bash

PC1> ip 192.168.1.10 255.255.255.0 192.168.1.1

###4. Verification (The Detective Work)

#1. Check the Status:
On R1, type show standby brief.

You should see R1 is Active and R2 is Standby.

The Virtual IP should be 192.168.1.1.

#2. The "Sabotage" Test (The most important part!):

1.On the PC, start a continuous ping to the gateway: ping 192.168.1.1 -t

2.While the ping is running, go to R1 and shut down the interface:
R1(config-if)# shutdown

3.Watch the PC: You might lose 1 or 2 pings, but then the pings will start working again!

4.Check R2: Type show standby brief. R2 will now say it is Active.

###5. Final Checklist for Submission
[ ] R1 and R2 are in the same HSRP group.

[ ] Both routers share the 192.168.1.1 virtual address.

[ ] The PC is using 192.168.1.1 as its gateway.

[ ] Save all configs with write memory.

# Red Team Operator Roadmap – 1 yil (haftalik reja, Python bilan)

---

## 🔹 1–2-oy: IT asoslari (8 hafta)

**Maqsad:** tizim va tarmoqni tushunish + Python boshlash.

- **1-hafta:** TCP/IP, subnetting. Python: `print`, variables.
- **2-hafta:** DNS, HTTP/HTTPS, FTP. Python: loops, conditions.
- **3-hafta:** Linux asoslari (terminal, fayl tizimi). Python: functions.
- **4-hafta:** Linux scripting (bash, cron). Python: file I/O.
- **5-hafta:** Windows asoslari (cmd, PowerShell). Python: `os` moduli.
- **6-hafta:** Windows user management. Python: `subprocess` moduli.
- **7-hafta:** VirtualBox/VMware’da lab qurish. Python: error handling.
- **8-hafta:** Tarmoq topologiyalari. Python: socket kirish.

🎯 **Natija:** Lab tayyor + Python asoslari.

---

## 🔹 3–4-oy: Kiberxavfsizlik poydevori (8 hafta)

**Maqsad:** xavfsizlik vositalari va Python’ni xavfsizlikka qo‘llash.

- **9-hafta:** Nmap (port scan). Python: oddiy port scanner.
- **10-hafta:** Nmap NSE scriptlari. Python: service banner grabber.
- **11-hafta:** Wireshark (trafik tahlili). Python: packet sniffer (scapy).
- **12-hafta:** Burp Suite (web request interception). Python: `requests` bilan HTTP GET/POST.
- **13-hafta:** OSINT (Google Dorking). Python: web scraping (BeautifulSoup).
- **14-hafta:** Shodan API. Python: Shodan bilan avtomatlashtirish.
- **15-hafta:** Bash scripting (Linux avtomatlashtirish). Python: `subprocess` orqali command run.
- **16-hafta:** PowerShell scripting. Python: JSON bilan ishlash.

🎯 **Natija:** Junior xavfsizlikchi + OSINT + Python tool yozish.

---

## 🔹 5–6-oy: Pentesting asoslari (8 hafta)

**Maqsad:** web va tarmoq zaifliklarini o‘rganish.

- **17-hafta:** OWASP Top 10 kirish (SQLi, XSS). Python: oddiy SQLi tester.
- **18-hafta:** SQLi exploit (sqlmap). Python: SQLite injection script.
- **19-hafta:** XSS amaliyoti. Python: XSS payload generator.
- **20-hafta:** RCE zaifliklari. Python: command injection exploit.
- **21-hafta:** SMB, FTP hujumlari. Python: SMB brute force tool.
- **22-hafta:** Metasploit Framework asoslari. Python: Metasploit RPC bilan ishlash.
- **23-hafta:** Linux privilege escalation. Python: SUID checker.
- **24-hafta:** Windows privilege escalation. Python: Registry enum tool.

🎯 **Natija:** Pentester Junior + Python exploit yozish.

---

## 🔹 7–8-oy: Advanced pentesting (8 hafta)

**Maqsad:** AD va post-exploitation.

- **25-hafta:** Active Directory asoslari. Python: LDAP query tool.
- **26-hafta:** BloodHound bilan AD mapping. Python: Neo4j query integration.
- **27-hafta:** Kerberoasting hujumi. Python: Ticket dumper.
- **28-hafta:** Pass-the-Hash. Python: Impacket kutubxonasi.
- **29-hafta:** Mimikatz ishlatish. Python: LSASS dump parser.
- **30-hafta:** Cobalt Strike kirish. Python: custom C2 agent (oddiy).
- **31-hafta:** EDR bypass asoslari. Python: obfuscation script.
- **32-hafta:** Custom payload yozish. Python: reverse shell script.

🎯 **Natija:** Red Team Operator Junior darajasi.

---

## 🔹 9–12-oy: Red Team uslubi (16 hafta)

**Maqsad:** MITRE ATT&CK asosida haqiqiy hujumlarni mashq qilish.

- **33-hafta:** MITRE ATT&CK overview. Python: MITRE tactic mapper.
- **34-hafta:** Initial Access (phishing). Python: phishing mail sender.
- **35-hafta:** Persistence (backdoor). Python: startup persistence script.
- **36-hafta:** Lateral Movement (RDP, SMB). Python: pass-the-hash tool.
- **37-hafta:** C2 kanallari (DNS tunneling). Python: DNS tunnel client.
- **38-hafta:** Data exfiltration. Python: covert file transfer.
- **39-hafta:** Defense evasion (log cleaning). Python: log wiper.
- **40-hafta:** Mini Red Team senariy (lab’da). Python: exploit chaining.
- **41-hafta:** Purple Team mashq. Python: attack simulation script.
- **42-hafta:** Hujum natijalarini hujjatlashtirish. Python: report generator.
- **43-hafta:** OSCP/CRTO tayyorgarlik. Python: automation scripts review.
- **44-hafta:** HackTheBox (Python exploit o‘zgartirish).
- **45-hafta:** TryHackMe (Red Team lab). Python: enumeration automation.
- **46-hafta:** Real-world ssenariy (AD + phishing + exfil).
- **47-hafta:** Team-based hujum mashqlari.
- **48-hafta:** Yil yakunida o‘z skill setini tekshirish.

🎯 **Natija:** Mustaqil Red Team operatori.
